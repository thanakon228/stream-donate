💰 การบริจาค

💥 Epic Alert — แสดงเอฟเฟกต์พิเศษเมื่อโดเนทสูง

เมื่อโดเนทถึงยอดที่กำหนด Overlay จะเปลี่ยนเป็น animation สุดอลังการ 5 แบบ

แทนที่ alert ปกติเมื่อถึงยอด
💡 ตัวอย่าง: เปิดใช้ + ยอดขั้นต่ำ 50 → โดเนท ฿50 ขึ้นไปจะได้ Epic Alert แทน alert ธรรมดา

🧾 ระบบแนบสลิปก่อนโดเนท

บังคับให้ผู้บริจาคแนบสลิปก่อนเข้าหน้าโดเนท — ทำงานได้ทันทีโดยไม่ต้องมี API Key

เด้ง gate ก่อนเข้าหน้าโดเนท
บล็อคถ้าไม่อัปโหลด
🔑 ยืนยันอัตโนมัติด้วย EasySlip (ไม่บังคับ)
ถ้าไม่มี API Key — ผู้บริจาคแนบสลิปและพิมพ์ยอดเองได้ (แบบ manual)
📌 ไม่มี API Key: Gate แสดง → อัปโหลดสลิป → พิมพ์ยอดเอง → ดำเนินการต่อ
🔍 มี API Key v1: POST multipart · field file → developer.easyslip.com
🔍 มี API Key v2: POST multipart · field file → api.easyslip.com/v2/verify/bank

🚀 Railway Raw Config — บันทึกการตั้งค่าทั้งหมดถาวร

การตั้งค่าทุกอย่าง (บัญชี, สลิป, bot, emotions ฯลฯ) จะ ไม่หายแม้ redeploy

💡 ตัวแปร CONFIG เก็บ config ทั้งหมดเป็น JSON · individual vars (ELEVENLABS_API_KEY ฯลฯ) จะ override CONFIG เสมอ

🎭 ตั้งค่าอารมณ์ TTS

🎧 ElevenLabs — Voice Settings ตามอารมณ์

Stability ต่ำ = อารมณ์ชัดขึ้น  |  Style สูง = เน้นย้ำอารมณ์มากขึ้น  |  Similarity = ความใกล้เคียงเสียงต้นแบบ

🔵 Google TTS — อารมณ์ด้วย Prosody

Speaking Rate = ความเร็ว (1.0 = ปกติ)  |  Pitch = ระดับเสียง (semitones)  |  Volume = ความดัง (dB)

0.5x ช้า1.0x ปกติ2.0x เร็ว
-10 เสียงต่ำ0 ปกติ+10 เสียงสูง
-6 เบา0 ปกติ+6 ดัง
